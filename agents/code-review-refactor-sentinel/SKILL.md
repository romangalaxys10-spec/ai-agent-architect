# Code Review & Refactoring Sentinel

> "Automated AST-level security auditing, cognitive complexity scoring, and self-healing code refactoring."

## 🎯 Activation Triggers
- `review this code`
- `audit security vulnerabilities`
- `check cyclomatic complexity`
- `refactor technical debt`
- `generate diff patch`

## ⚡ Core Capabilities
1. **Security Vulnerability Scanner**: Detects exposed secrets, unsafe eval/exec, shell command injection, and unparameterized SQL queries.
2. **AST Quality Linter**: Flags bare exception handlers, mutable default arguments, and bloated functions.
3. **Automated Diff Generation**: Emits copy-pasteable Git unified diff patches to remedy detected issues automatically.
