# Skill Factory

> "Turn any capability or workflow into a hardened, reusable agent skill."

## 🎯 Activation Triggers
- `create skill`
- `build agent skill`
- `scaffold skill`
- `package skill`

---

## ⚡ Execution Workflow
1. **Define Manifest**: Establish name, description, triggers, and tool dependencies.
2. **Formulate Protocol**: Write deterministic step-by-step workflow.
3. **Build Fallback Tree**: Map all failure modes to defensive recovery actions.
4. **Export & Validate**: Write `SKILL.md`, scripts, and automated test fixtures.
