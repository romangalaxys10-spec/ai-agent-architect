# Last 30 Days Research Sub-Agent

> "Real-time, engagement-weighted intelligence from the trailing 30 days across developer communities."

## 🎯 Activation Triggers
- `last 30 days research`
- `trending in the last month`
- `recent community consensus`
- `latest tool benchmarks`

## ⚡ Execution Protocol
1. **Recency Anchor (30-Day Window)**: Filter all technical queries strictly within the trailing 30-day window.
2. **Multi-Source Triangulation**: Aggregate signals across GitHub releases, Hacker News, Reddit, and X/Twitter.
3. **Engagement-Weighted Filtering**: Filter out SEO content farms in favor of real developer discussions and production post-mortems.
4. **Citation & Evidence Provenance**: Back every finding with verifiable timestamps and reference links.
