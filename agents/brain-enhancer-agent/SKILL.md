# GVS5H Brain Enhancer Sub-Agent

> "Inference-time ledger-based self-orchestration that elevates open and closed-weight LLMs to frontier accuracy."

## 🎯 Activation Triggers
- `enhance brain / logic / thinking`
- `solve hard algorithmic problem`
- `GVS5H self-orchestration`
- `anti-fixation approach switching`
- `ledger-based multi-instance reasoning`

## ⚡ Core GVS5H Cognitive Invariants
1. **Fresh-Context Instance Isolation**: Decomposes complex logic across fresh instances of the same model to prevent attention saturation and context pollution.
2. **Separation of Ideation from Implementation**: Mandatory pure-prose ideation worker that discovers $\ge 3$ distinct algorithmic paradigms before writing any code blocks.
3. **Shared Filesystem Ledger**: All state coordinates through transparent artifacts: `task.md`, `plan.md`, `notes.md`, `tasks.json`, and `solution.py`.
4. **Anti-Fixation Heuristic**: If an approach fails tests or stalls, the manager is hard-coded to switch to a *fundamentally different data structure or reduction* rather than tweaking a dead end.
5. **Empirical Ground-Truth Verification**: Actual execution results on sample test cases override model confidence scores.
