# Agent Studio Dashboard Plugin

> "Live visual telemetry, swarm topology inspector, and OpenTelemetry trace waterfalls for autonomous multi-agent systems."

## 🎯 Activation Triggers
- `open agent studio`
- `start swarm dashboard`
- `view agent traces`
- `monitor multi-agent bus`

## ⚡ Core Capabilities
1. **Live Swarm Topology**: Visualizes currently registered and executing sub-agents.
2. **OpenTelemetry Span Inspector**: Shows step-by-step latency, token burns, and execution waterfalls.
3. **A2A Correlation Viewer**: Real-time logging of inter-agent messages and handoff intents.
