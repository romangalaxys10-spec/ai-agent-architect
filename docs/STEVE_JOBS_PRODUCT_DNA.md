# Steve Jobs Product DNA for AI Agents
*Applying Uncompromising Taste, Focus, and Craft to Autonomous Intelligence*

> "People think focus means saying yes to the thing you've got to focus on. But that's not what it means at all. It means saying no to the hundred other good ideas that there are." — Steve Jobs

---

## 1. The Core Philosophy
Most AI agents built today are **cluttered, bloated, and mediocre**. They try to do 50 things poorly, spew hedged walls of text, and fail when encountering real-world edge cases.

Building an **Insanely Great** agent requires applying Steve Jobs' product philosophy:

### I. The Whole Widget (End-to-End Control)
* *Principle:* Don't build a disconnected script and blame the model when it breaks. Own the prompt, the tools, the execution sandbox, the error fallbacks, and the output presentation.
* *Application:* An agent must take full responsibility for delivering the final result to the user.

### II. Focus = Saying NO to 1,000 Features
* *Principle:* Radical reduction. If an agent does not need a tool, remove it. If a prompt contains boilerplate fluff, delete it.
* *Application:* Every agent must have a **1-sentence radical definition** of what it does. If you cannot describe it in one sentence, the architecture is broken.

### III. Invisible Craft (The Back of the Fence)
* *Principle:* A great carpenter does not use cheap plywood for the back of a cabinet just because no one will see it.
* *Application:* Clean codebase, strict type hints, elegant unit tests, and robust error handlers under the hood.

### IV. Radical Binary Judgment
* *Principle:* Eliminate hedging words ("maybe", "kind of", "it seems"). Products and outputs are either **Insanely Great** or **Total Bullshit**.
* *Application:* Build self-evaluators that reject mediocre outputs and trigger auto-refinement loops.

## 2. The 6 Mental Models for Agent Architects

| Mental Model | Agent Architectural Meaning |
|---|---|
| **1. Focus = Saying No** | Prune unused tools and bloated prompts; maximize signal-to-noise ratio. |
| **2. The Whole Widget** | End-to-end integration of Perception, Logic, Sandbox, and Interface. |
| **3. Connecting the Dots** | Trust structured modular design; individual skills compose into emergent capability. |
| **4. Death Filter** | Eliminate superfluous abstractions; solve the critical bottleneck right now. |
| **5. Reality Distortion Field** | Push agent capabilities beyond conventional boundaries via multi-step chaining. |
| **6. Technology × Humanities** | Technical execution paired with intuitive, human-centered output formatting. |
